# Aliens Shooter

Космический коридорный рогалик в духе Archero для Telegram Mini App.
Вид 3/4 сверху, автоматическая стрельба, 15 секторов, боссы каждые 3 сектора
проходят в 3D от первого лица (рейкастер).

## Запуск

Статика, без сборки и бэкенда. Любой http-сервер:

```
python -m http.server 8080
```

Открыть `http://localhost:8080/`. 3D-арена отдельно: `/boss3d3.html`.

## Что внутри

- 15 секторов, 5 боссов (3, 6, 9, 12, 15), трое из них — 3D-арена
- 6 стволов с дефицитными патронами, выдача после боссов
- перки, магазин на паузе, контракты перед боссом, дрон-компаньон
- модификаторы секторов: лёд, турели, улей, темнота (фонарь), кислота
- метапрогрессия, ежедневный забег по сиду даты, рекорды, облачные сохранения
- Telegram WebApp: кнопки, тактильная отдача, CloudStorage

## Управление

Один палец: стик появляется там, где нажал. Стрельба, наводка и в 3D камера —
автоматические.
